# Strujomerko dokumentacija

Javni repozitorijum dokumentacije za Strujomerko smart meter platformu.

Dokumentacija: [misadeks.github.io/strujomerko-docs](https://misadeks.github.io/strujomerko-docs/)

## Lokalni pregled

```powershell
python -m pip install mkdocs
python -m mkdocs serve
```

Zatim otvoriti:

```text
http://127.0.0.1:8000
```

Slike i dijagrami se dodaju u `docs/slike/`.
